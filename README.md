# 天庭漫游 · Heavenly Court Roam

一个基于 [Three.js](https://threejs.org/) 的沉浸式 3D 天宫漫游体验。夜幕下穿行于云海、殿宇与星官之间，沿着若隐若现的薄纱月桥，解锁多套东方神话玩法。

## ✨ 玩法

- **凤凰引路** — 召唤引路凤凰，带你前往最近的玉简地标。
- **星宿连线** — 8 组星官对应 8 座空殿，顺序点星、连线，点亮殿宇。
- **云海垂钓** — 向云海抛钩，浮标、涟漪与钓起之物皆有名目。
- **镜池水中天** — 潜入镜池，倒悬宫殿、青蓝雾气与锦鲤迎面而来。
- **月相门** — 依朔望推算满月窗口，生成横渡的月光桥。
- **御道登阶** — 5 级阶口，双语典故问答，登顶天庭。

## 🎮 操作

- 拖拽旋转视角 · 滚轮缩放 · 点击建筑聆听语音讲解
- 顶栏可切换：昼夜流转 / 流星雨 / 语音讲解 / 自动漫游 / 瑞兽图鉴 / 仙箓册 / 玩法 / 重置视角
- 移动端自适应，底部抽屉式面板

## 🚀 本地运行

需通过本地静态服务器打开（ES Module 不支持 `file://` 直接加载）：

```bash
# 任选其一，在项目根目录执行
python -m http.server 8137
# 或
npx serve .
```

然后浏览器访问 `http://localhost:8137/`。

> 低配 / 软件渲染环境可在地址后加 `?nobloom=1` 跳过后处理以保帧率。

## 🧱 技术栈

- Three.js **r161**（核心 + OrbitControls + postprocessing 后处理 + 自定义 GLSL 着色器）
- 自定义 `ShaderMaterial`：FBM 噪声、经纬织纹薄纱桥、菲涅尔荧光、沿桥流光
- WebAudio 合成音效
- 纯前端，无构建步骤

## 📁 目录结构

```
index.html        # 入口：UI 样式、importmap、挂载点
main.js           # 全部场景逻辑与玩法（~60000 行级）
vendor/           # Three.js r161 核心与扩展（本地内置，离线可运行）
```

## 📜 说明

本项目为个人创意作品，Three.js 以本地 `vendor/` 形式内置，仓库可完全离线运行。
